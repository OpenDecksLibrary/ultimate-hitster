# Source data

The schema-v1 catalogue contains Original France only. Recordings, editions
and numbered memberships are separate, with exact provider references, source
snapshots, optional albums and audio verification evidence.

See [schema](../docs/DATA_MODEL.md), [source provenance](sources/README.md)
and [production commands](../docs/PRODUCTION_WORKFLOW.md). Preserve IDs through
reviewed imports/corrections.
