for validation; no other editions are included and no stable release is claimed.

## Features

- All 308 catalogue cards, preserving card numbers, artists, titles and years.
- Exact pinned recording references, optional provider album information, and
  short MP3 excerpts rather than complete songs.
- Only the audio player on the front. Year, title, artist and album on the back.
- Stable production identities and recording deduplication; shared online/offline
  note identities preserve progress when switching mode.
- Existing one-card and ten-card playback prototypes remain available in source.

## Update without losing progress

1. Back up/synchronize your collection, then import the new APKG into the existing
   collection. **Do not delete the existing production deck or notes.**
2. Online and offline are alternatives for the same production notes, not two
   independent study decks. Import the desired mode to replace its player.
3. When switching to an older or equal-timestamp package, set **Update existing
   notes: Always** in the Anki import options. Use packages from the same release
   when comparing modes: that setting also imports the file's metadata.
4. Finish media sync before testing offline playback on another device.

Production deck/model/note identities are unchanged from the full-edition PR #3
validation packages. Prototype identities are deliberately separate; there is
no automatic transfer of progress from the one-card or ten-card prototypes.

## Validation and known limitations

Publication runs the automated tests, downloads and fully decodes every selected
MP3, generates both packages, imports all 308 notes into a disposable Anki
collection and verifies review-history/scheduling retention during a mode change.
The release report records the exact build results. SHA-256 checks cover the
uploaded assets, and public downloads are checked after publication.

The complete edition still needs manual playback/layout validation. Earlier
native and HTML5 MP3 prototypes were reported working by the user; mobile clients
are **not** claimed validated. Import/decoder tests do not establish audible
playback, layout, media synchronization or compatibility on every Anki client.

Seven catalogue labels differ from the pinned provider version labels. They are
explicitly reviewed and tagged `reference::reviewed`, without changing recording
IDs or silently substituting another song. Compare these with the physical box:

The Hitify table is a normalized public-table snapshot because direct HTTP
access returned 403 during collection. The attributed community card-reference
CSV covers all 308 positions. Its first 100 IDs match the public Hitify-linked
playlist prefix; that truncated embed did not independently expose the other
208 positions. Exact provider metadata was checked for all 308 IDs. No physical
card scan or independently verified printed years are claimed.

The 110 provider release-date/catalogue-year differences remain documented;
catalogue years are retained, and albums can reflect reissues. See
[the provenance and validation record](https://github.com/OpenDecksLibrary/ultimate-hitster/blob/v0.2.0-beta.1/docs/ORIGINAL_FRANCE_VALIDATION.md).

Remote URLs can expire or become unavailable, and region/client restrictions can
affect playback. Checked availability is time-specific. Maintainers can refresh
the pinned URLs and rebuild; stable note IDs preserve progress. No account or
streaming subscription is required for the supplied preview URLs at build time.
Audio remains third-party content; the source-code license does not grant rights
to redistribute complete recordings or reuse these excerpts elsewhere.

Please report problems with card number, package mode, Anki version and OS.
