## Import and update without losing progress

Back up the collection. Import into the existing collection without deleting
production notes or decks. For an equal/older-timestamp alternative, select
Update existing notes: Always. Online and offline update the same notes.

**Enable Import learning progress / Include scheduling** to retain the
suspension state of newly imported cards without audio. Engine tests check that
existing scheduling, review history and personal deck placement remain intact.
If that option is disabled, Anki resets new-card suspension.

After an upgrade, search in Browse:

~~~text
tag:audio::missing Playback:*unavailable*
~~~

Suspend any active results. This also handles exception cards already imported
from a candidate, whose existing queues are intentionally preserved. Tags can
persist after a correction; the Playback condition excludes restored players.
Review restored cards separately before unsuspending them. See
[the complete unavailable-audio procedure](../MISSING_AUDIO.md).

Shared cards stay in their current deck when wider selections are imported.
New universal cards go into Ultimate Hitster; the legacy Original France package
retains its deck identity. Use edition tags and filtered decks for overlapping
collections. A smaller selection does not remove previously imported cards.

clients. Automated decoding/import tests do not establish GUI/device playback.

references, recheck audio, then rebuild. Different Spotify IDs are not merged
solely by similar names or identical excerpts. No stable release is claimed.
